# Airline Reservation System frontend

This React application is the website for the Airline Reservation System. For the complete project overview, requirements, database setup, and backend instructions, see the [project README](../README.md).

## Run locally

From this directory:

```powershell
npm install
npm start
```

The development website runs at `http://localhost:3000`. The backend should be running at `http://localhost:8080`; the API URL is configured in `src/services/Api.js`.

## Other commands

```powershell
npm test
npm run build
```
